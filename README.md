# Exploratory-Data-Analysis-on-TITANIC-dataset
## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The goal is to understand passenger data and identify factors associated with survival.

## Tools Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset Information

* Total records: 891
* Total columns: 12
* Missing values were identified and handled where appropriate.

## Key Findings

* The overall survival rate was approximately 38.38%.
* Female passengers had a higher survival rate than male passengers.
* First-class passengers had a higher survival rate than third-class passengers.
* The average passenger age was approximately 29.36 years.
* Some fare values were identified as potential outliers.

## Conclusion

The analysis helped identify survival patterns based on gender, passenger class, age, and fare. It also provided experience in data cleaning, visualization, and exploratory data analysis using Python.
